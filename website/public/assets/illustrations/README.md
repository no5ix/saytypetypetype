# Feature illustrations

Generated with the built-in image_gen tool for VoicePaste's marketing website. They are conceptual illustrations, not screenshots of the app.

- `templates-transparent.png`: scattered spoken ideas organized into different document forms.
- `hotwords-transparent.png`: personal vocabulary illustrated with VoicePaste, Ollama and macOS.
- `prompts.json`: original production prompts and generator record.

The current images have transparent backgrounds for light and dark themes. The original dark-background artwork was replaced; generated originals remain outside the project in the generation folder. The same artwork is used in Chinese and English; feature headings, descriptions and image alt text remain real server-rendered, localized HTML.
