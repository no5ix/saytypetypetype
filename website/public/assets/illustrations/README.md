# Feature illustrations

Generated with the built-in image_gen tool for VoicePaste's marketing website. They are conceptual illustrations, not screenshots of the app.

- `templates.png`: scattered spoken ideas organized into different document forms.
- `hotwords.png`: personal vocabulary illustrated with VoicePaste, Ollama and macOS.
- `prompts.json`: complete production prompts and generator record.

Both files were copied into this project from the generated-image output. Originals remain in the generation folder. The same artwork is used in Chinese and English; feature headings, descriptions and image alt text remain real server-rendered, localized HTML.
