---
title: "Transcription models"
description: "Online: choose a provider in Audio Model → Online Models, enter your own credentials, and save. Provider pricing and data policies apply."
---

Volcengine: activate streaming recognition in the Doubao Speech console, create an API key, then enter the credentials in VoicePaste.

ElevenLabs: create a key in ElevenAPI → API Keys and enable Speech to Text access.

Local: select and download a model in Audio Model → Local Models, then enable it. Required VAD and punctuation models are configured alongside it.

Language, hotword and live-preview support vary by model. Start with the default settings and adjust as needed.
