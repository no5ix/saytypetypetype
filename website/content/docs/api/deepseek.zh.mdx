title: "DeepSeek"
---

DeepSeek 在 VoicePaste 中用于文本翻译与润色，不负责语音识别。只使用语音转文字时，无需配置。

## 1. 申请 API Key

1. 登录 [DeepSeek 开放平台](https://platform.deepseek.com/)。
2. 打开 [API keys](https://platform.deepseek.com/api_keys)，创建一个密钥并保存。
3. 在平台检查 API 账户的余额和可用服务。

## 2. 配置 VoicePaste

1. 打开「设置 → 大语言模型」，选择 DeepSeek。
2. 填写 API Key。接口地址可使用应用预设的 `https://api.deepseek.com/v1/chat/completions`。
3. 模型名称需使用当前 API 支持的标识，可以先使用应用预设。
4. 完成字段编辑后继续配置文本模板。

这里的接口地址是完整的 Chat Completions 请求地址；不要把官网首页或控制台地址填入该字段。

## 3. 验证翻译或润色

1. 在「文本润色」添加模板，例如「翻译为英文」，并填写提示词。
2. 到「设置 → 快捷键」为该模板绑定按键。
3. 在输入框中说一句话，使用模板快捷键完成，检查是否输出翻译结果。

完整流程见 [大语言模型与润色模板](/zh/docs/templates)。仅保存密钥不能证明实际调用成功。

## 常见问题

### 鉴权失败怎么办？

检查密钥是否完整、是否属于当前 API 账户。

### 余额或额度不足怎么办？

在开放平台检查 API 计费状态。网页聊天账户的使用情况不代表 API 已有可用额度。

### 提示模型不存在怎么办？

按 [DeepSeek 官方文档](https://api-docs.deepseek.com/) 核对并更新 API 模型名称，不要填写网页聊天模式的显示名称。

### 识别有文字但润色失败怎么办？

语音识别与 DeepSeek 是两个独立环节，分别检查配置。
