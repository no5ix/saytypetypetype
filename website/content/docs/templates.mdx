## 1. Configure a language model

Speech recognition turns audio into text. A language model translates, organizes, or polishes that text. It is optional for plain transcription.

1. Open Settings → Large Language Model and choose a provider.
2. For an online service, enter your own API key. See the [DeepSeek API guide](/en/docs/api/deepseek) for an example.
3. Set the endpoint and model name as required by the provider. Start with app defaults for presets. Custom services need a compatible Chat Completions interface.
4. Template requests use the single currently selected provider.

For Ollama, install and run it locally and download a language model first. Then select Ollama in VoicePaste and enter the installed model's name. The service address must point to the running instance.

## 2. Add a text template

1. In the Text Polishing section on the same page, add a template or choose one from the built-in prompts.
2. Give it a recognizable name, such as “Translate to English.”
3. Write a specific instruction, for example:

> Translate the input into natural English. Preserve its meaning and output only the translation.

## 3. Bind and use a shortcut

1. Open Settings → Shortcuts and set the template's keys.
2. Start recording in an input field and finish with that template's shortcut according to the current mode.
3. Check that the result matches your instruction. See [Shortcuts and input](/en/docs/hotkeys).

## Common questions

### What if recognition works but polishing fails?

Check the language provider's key, model name, endpoint, and quota separately. Recognition and polishing may use different providers.

### What if the result includes explanations?

Ask for only the processed result in your prompt, then test a short sentence.

### How can I keep all processing local?

Use both local recognition and a local language model, or use plain transcription without polishing.
