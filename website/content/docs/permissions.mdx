## macOS

### Microphone

1. In VoicePaste, open Settings → System Permissions.
2. Use the microphone check button and allow access in the system prompt.
3. Return to the app, check again, and confirm access is granted.

### Accessibility

Accessibility permission lets VoicePaste enter text into other apps.

1. In Settings → System Permissions → Accessibility, use the button to open system settings.
2. Find VoicePaste under Privacy & Security → Accessibility and turn on its switch.
3. Authenticate with your password or Touch ID if requested. Return to VoicePaste and check its permission status.

## Windows

### Microphone

1. Open Settings → Privacy & security → Microphone. Enable microphone access and access for desktop apps. On Windows 10, the path starts with Settings → Privacy → Microphone.
2. Return to VoicePaste and use the microphone check button under System Permissions.
3. Windows does not require macOS Accessibility permission.

## Common questions

### How can I verify that permissions work?

Record into a text editor and check both recognition and automatic paste. Opening a system settings page alone does not grant permission.

### What if I previously denied microphone access on macOS?

Open System Settings → Privacy & Security → Microphone and enable VoicePaste, then check permission again in the app.

### What if VoicePaste is missing from macOS Accessibility settings?

Use the add button below the list, select the currently installed VoicePaste app from Applications, and turn on its switch.

### What if automatic paste fails after reinstalling?

Check that the Accessibility entry points to the currently installed app. Remove the old entry and add the current app if needed.

### What if access is granted but recording fails?

Check the system input device and whether the microphone is muted, then check permission again.

### What if Windows blocks installation?

After confirming that the installer came from this site's [download page](/en/downloads), choose “More info → Run anyway” in the SmartScreen notice. If the option is unavailable or organization policy blocks the app, contact your device administrator.

### What if Windows Firewall prompts me?

Confirm that it names VoicePaste and allow that app only when needed. You do not need to disable the firewall. See [Microsoft's firewall guidance](https://support.microsoft.com/en-us/windows/security/firewall/risks-of-allowing-apps-through-windows-firewall).
