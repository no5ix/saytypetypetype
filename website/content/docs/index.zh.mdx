title: "快速开始"
---

## 1. 下载并安装

1. 打开 [VoicePaste 下载页面](/zh/downloads)，根据操作系统选择安装包。
2. macOS 用户根据芯片选择 Apple Silicon 或 Intel 版本；Windows 用户选择 x64 安装包。
3. 安装完成后打开 VoicePaste，进入设置。

**Windows 用户请注意**：安装时可能出现系统安全提示，处理方式见文末 [常见问题](#常见问题)。

## 2. 开启系统权限

1. 打开「设置 → 系统权限」，点击麦克风旁的「检测」，按系统提示允许访问。
2. macOS 还需要开启辅助功能权限，用于将识别文字粘贴到其他应用。
3. 返回 VoicePaste，确认所需权限显示「已授权」。

具体操作见 [系统权限](/zh/docs/permissions)。

## 3. 配置语音识别模型

语音识别模型（ASR）负责把声音转换为文字。在线和本地模型任选一种即可。

- **在线识别**：先按 [火山引擎（豆包语音）](/zh/docs/api/volcengine) 或 [ElevenLabs](/zh/docs/api/elevenlabs) 教程申请 API Key，再到「设置 → 音频模型 → 在线模型」填写凭证、保存并启用。
- **本地识别**：在「设置 → 音频模型 → 本地模型」选择模型，下载完成后启用，无需申请 API Key。

选择建议和下载步骤见 [识别模型](/zh/docs/models)，支持范围见 [模型兼容清单](/zh/docs/compatibility)。

## 4. 配置大语言模型（可选）

需要翻译、整理或润色时，在「设置 → 大语言模型」配置提供商，并添加文本模板。只需要语音转文字时可以跳过。

可以参考 [DeepSeek API 申请](/zh/docs/api/deepseek)，然后按 [大语言模型与润色模板](/zh/docs/templates) 配置。

## 5. 设置快捷键并完成首次输入

1. 打开「设置 → 快捷键」，查看当前绑定，选择免提模式或按住说话。
2. 打开记事本等应用，点击输入框，再用快捷键开始录音。
3. 说一句话，按当前模式结束录音，确认文字出现在输入框中。

操作方式见 [快捷键与输入](/zh/docs/hotkeys)。

## 常见问题

### Windows 提示「已保护你的电脑」怎么办？

先确认安装包来自本站 [下载页面](/zh/downloads)，再点击「更多信息 → 仍要运行」。其他拦截或防火墙提示见 [系统权限的常见问题](/zh/docs/permissions#常见问题)。

### 录音结束后没有文字输出怎么办？

先检查系统权限、当前启用的识别模型，以及目标输入框是否有焦点。具体排查见 [系统权限](/zh/docs/permissions#常见问题) 和 [识别模型](/zh/docs/models#常见问题)。
