## macOS

### 麦克风

1. 打开 VoicePaste 的「设置 → 系统权限」。
2. 点击「麦克风」旁的「检测」，在系统弹窗中允许访问。
3. 返回应用，再次检测，确认显示「已授权」。

### 辅助功能

辅助功能权限用于把文字输入到其他应用。

1. 在「设置 → 系统权限 → 辅助功能」点击「前往授权」。
2. 在系统的「隐私与安全性 → 辅助功能」列表中找到 VoicePaste，打开旁边的开关。
3. 如系统要求，使用密码或 Touch ID 确认；返回 VoicePaste，检查授权状态。

## Windows

### 麦克风

1. 在「设置 → 隐私和安全性 → 麦克风」中开启麦克风访问，并允许桌面应用访问麦克风。Windows 10 的入口位于「设置 → 隐私 → 麦克风」。
2. 返回 VoicePaste，在「系统权限」中点击「检测」。
3. Windows 不需要 macOS 的辅助功能授权。

## 常见问题

### 如何确认权限已经生效？

在记事本或其他输入框中完成一次录音，确认可以识别并自动粘贴。仅打开系统设置页面并不代表已完成授权。

### 之前拒绝了 macOS 麦克风授权怎么办？

打开「系统设置 → 隐私与安全性 → 麦克风」，开启 VoicePaste 的开关，再返回应用检测权限。

### macOS 辅助功能列表中找不到 VoicePaste 怎么办？

点击列表下方的添加按钮，从「应用程序」中选择当前安装的 VoicePaste，再开启旁边的开关。

### 重装后无法自动粘贴怎么办？

检查辅助功能列表中的 VoicePaste 是否为当前安装的应用；必要时移除旧条目并重新添加。

### 已授权但无法录音怎么办？

检查系统输入设备及麦克风是否被静音，再重新检测权限。

### Windows 安装被拦截怎么办？

确认安装包来自本站 [下载页面](/zh/downloads) 后，可在 SmartScreen 提醒中点击「更多信息 → 仍要运行」。若没有此选项，或提示由组织策略阻止，请联系设备管理员。

### Windows 防火墙弹出提示怎么办？

确认提示中的应用为 VoicePaste，仅在需要时允许该应用通过，无需关闭整个防火墙。操作见 [Microsoft 防火墙说明](https://support.microsoft.com/en-us/windows/security/firewall/risks-of-allowing-apps-through-windows-firewall)。
