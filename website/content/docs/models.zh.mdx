---

火山引擎：在豆包语音控制台开通流式语音识别服务，创建 API Key，再将凭证填入 VoicePaste。

ElevenLabs：在 ElevenAPI 的 API Keys 页面创建密钥，并启用 Speech to Text 权限。

本地识别：在「音频模型 → 本地模型」选择模型并下载，下载完成后启用。所需 VAD 与标点模型会一起配置。

各模型支持的语言、热词与实时预览方式不同。先使用默认参数，再按需要调整。
